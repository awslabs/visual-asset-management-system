# Comments API

The Comments API attaches free-text comments to a specific version of an asset. Comments support asset review workflows: a reviewer records an observation against the version they inspected, and the comment stays bound to that version as the asset evolves.

:::info[Authorization]
All endpoints require a valid JWT token in the `Authorization` header. Comment endpoints enforce Casbin authorization against the **owning asset** using the `asset` object type, evaluated for the database in the request path — there is no separate comment object type. A caller who can read an asset can read its comments, and a caller who can write an asset can add comments to it. The decision is made before the asset is looked up, so a caller who is refused gets `403` whether or not the asset exists.
:::

---

## Concepts

-   **Addressing**: The same asset ID can exist in more than one database, so every route names the asset by its database ID and asset ID: `/comments/database/{databaseId}/assets/{assetId}`.
-   **Comment identity**: A comment is identified by its `commentId`, which the API generates when the comment is created. One comment is addressed as `/comments/database/{databaseId}/assets/{assetId}/{commentId}`.
-   **Version scope**: Every comment is about one asset version, recorded in its `assetVersionId` field. The listing takes an optional `assetVersionId` query parameter to return the comments on one version.
-   **Ownership**: The user who creates a comment becomes its owner. Only the owner can edit or delete it, regardless of their asset permissions.
-   **Soft delete**: A deleted comment is kept apart from the asset's live comments rather than removed. It stops appearing in the asset's comment listings.

### Comment fields

| Field                  | Type   | Description                                                             |
| ---------------------- | ------ | ----------------------------------------------------------------------- |
| `commentId`            | string | Comment identifier, generated by the API.                               |
| `databaseId`           | string | Database of the asset the comment belongs to.                           |
| `assetId`              | string | Asset the comment belongs to.                                           |
| `assetVersionId`       | string | Asset version the comment is about.                                     |
| `commentBody`          | string | Comment text.                                                           |
| `commentOwnerID`       | string | User ID of the comment's creator.                                       |
| `commentOwnerUsername` | string | Display identity of the creator.                                        |
| `dateCreated`          | string | ISO 8601 creation timestamp.                                            |
| `dateEdited`           | string | ISO 8601 timestamp of the last edit. Present only on an edited comment. |

## Endpoints

### List comments for an asset

`GET /comments/database/{databaseId}/assets/{assetId}`

Retrieves the comments on an asset, newest first: every version's, or one version's when `assetVersionId` is given.

**Request Parameters:**

| Parameter        | Location | Type    | Required | Description                                                                  |
| ---------------- | -------- | ------- | -------- | ---------------------------------------------------------------------------- |
| `databaseId`     | path     | string  | Yes      | Database identifier of the asset.                                            |
| `assetId`        | path     | string  | Yes      | Asset identifier.                                                            |
| `assetVersionId` | query    | string  | No       | Only the comments on this asset version.                                     |
| `maxItems`       | query    | integer | No       | Maximum number of comments to return.                                        |
| `pageSize`       | query    | integer | No       | Number of comments per page.                                                 |
| `startingToken`  | query    | string  | No       | Pagination token.                                                            |
| `showArchived`   | query    | boolean | No       | When `true`, also lists the comments of an archived asset. Default: `false`. |

**Response:**

```json
{
    "message": [
        {
            "commentId": "c1a2b3c4-d5e6-7890-abcd-ef1234567890",
            "databaseId": "my-database",
            "assetId": "asset-001",
            "assetVersionId": "2",
            "commentBody": "The north facade needs a higher-resolution texture.",
            "commentOwnerID": "user@example.com",
            "commentOwnerUsername": "user@example.com",
            "dateCreated": "2026-03-15T10:30:00.000000Z"
        }
    ]
}
```

`message` is the comment array itself. The response carries no continuation token, so `maxItems` bounds the whole result set for a call rather than opening a page sequence.

**Error Responses:**

| Status | Description                                              |
| ------ | -------------------------------------------------------- |
| `400`  | Invalid `databaseId`, `assetId` or `assetVersionId`.     |
| `403`  | Not authorized to call this route or to read this asset. |
| `404`  | Asset not found.                                         |
| `405`  | Method not allowed.                                      |
| `500`  | Internal server error.                                   |

### Get a comment

`GET /comments/database/{databaseId}/assets/{assetId}/{commentId}`

Retrieves a single comment.

**Request Parameters:**

| Parameter      | Location | Type    | Required | Description                                                               |
| -------------- | -------- | ------- | -------- | ------------------------------------------------------------------------- |
| `databaseId`   | path     | string  | Yes      | Database identifier of the asset.                                         |
| `assetId`      | path     | string  | Yes      | Asset identifier.                                                         |
| `commentId`    | path     | string  | Yes      | Comment identifier.                                                       |
| `showArchived` | query    | boolean | No       | When `true`, also reads a comment of an archived asset. Default: `false`. |

**Response:**

```json
{
    "message": {
        "commentId": "c1a2b3c4-d5e6-7890-abcd-ef1234567890",
        "databaseId": "my-database",
        "assetId": "asset-001",
        "assetVersionId": "2",
        "commentBody": "The north facade needs a higher-resolution texture.",
        "commentOwnerID": "user@example.com",
        "commentOwnerUsername": "user@example.com",
        "dateCreated": "2026-03-15T10:30:00.000000Z"
    }
}
```

A comment that does not exist returns `200` with an empty `message` object rather than a `404`.

**Error Responses:**

| Status | Description                                              |
| ------ | -------------------------------------------------------- |
| `400`  | Invalid `databaseId`, `assetId` or `commentId`.          |
| `403`  | Not authorized to call this route or to read this asset. |
| `404`  | Asset not found.                                         |
| `500`  | Internal server error.                                   |

### Add a comment

`POST /comments/database/{databaseId}/assets/{assetId}`

Adds a comment about a version of an asset. The API generates the comment ID and returns it, and the caller becomes the comment's owner.

**Request Parameters:**

| Parameter    | Location | Type   | Required | Description                       |
| ------------ | -------- | ------ | -------- | --------------------------------- |
| `databaseId` | path     | string | Yes      | Database identifier of the asset. |
| `assetId`    | path     | string | Yes      | Asset identifier.                 |

**Request Body:**

| Field            | Type   | Required | Description                            |
| ---------------- | ------ | -------- | -------------------------------------- |
| `assetVersionId` | string | Yes      | Asset version the comment is about.    |
| `commentBody`    | string | Yes      | Comment text, up to 16,384 characters. |

```json
{
    "assetVersionId": "2",
    "commentBody": "The north facade needs a higher-resolution texture."
}
```

**Response:**

```json
{
    "message": "Succeeded",
    "commentId": "c1a2b3c4-d5e6-7890-abcd-ef1234567890"
}
```

**Error Responses:**

| Status | Description                                                                                              |
| ------ | -------------------------------------------------------------------------------------------------------- |
| `400`  | Invalid path parameters, a missing or empty `assetVersionId`, or a missing or over-length `commentBody`. |
| `403`  | Not authorized to write this asset.                                                                      |
| `404`  | Asset not found.                                                                                         |
| `500`  | Internal server error.                                                                                   |

---

### Edit a comment

`PUT /comments/database/{databaseId}/assets/{assetId}/{commentId}`

Replaces a comment's text and records a `dateEdited` timestamp. Only the comment's owner can edit it.

**Request Parameters:**

| Parameter    | Location | Type   | Required | Description                       |
| ------------ | -------- | ------ | -------- | --------------------------------- |
| `databaseId` | path     | string | Yes      | Database identifier of the asset. |
| `assetId`    | path     | string | Yes      | Asset identifier.                 |
| `commentId`  | path     | string | Yes      | Comment identifier.               |

**Request Body:**

| Field         | Type   | Required | Description                                        |
| ------------- | ------ | -------- | -------------------------------------------------- |
| `commentBody` | string | Yes      | Replacement comment text, up to 16,384 characters. |

**Response:**

```json
{
    "message": "Succeeded"
}
```

**Error Responses:**

| Status | Description                                                                    |
| ------ | ------------------------------------------------------------------------------ |
| `400`  | Missing or invalid path parameters, or a missing or over-length `commentBody`. |
| `403`  | Not authorized to write this asset, or the caller does not own the comment.    |
| `404`  | Asset not found, or the comment does not exist.                                |
| `500`  | Internal server error.                                                         |

---

### Delete a comment

`DELETE /comments/database/{databaseId}/assets/{assetId}/{commentId}`

Soft-deletes a comment. Only the comment's owner can delete it.

**Request Parameters:**

| Parameter    | Location | Type   | Required | Description                       |
| ------------ | -------- | ------ | -------- | --------------------------------- |
| `databaseId` | path     | string | Yes      | Database identifier of the asset. |
| `assetId`    | path     | string | Yes      | Asset identifier.                 |
| `commentId`  | path     | string | Yes      | Comment identifier.               |

**Response:**

```json
{
    "message": "Comment deleted"
}
```

**Error Responses:**

| Status | Description                                                                                           |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `400`  | Missing or invalid path parameters.                                                                   |
| `403`  | Not authorized to call this route or to delete on this asset, or the caller does not own the comment. |
| `404`  | Asset not found, or the comment does not exist.                                                       |
| `500`  | Internal server error.                                                                                |
